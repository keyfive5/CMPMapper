# 🚀 How to Use Your Generated Multi-Site Rule

## Step-by-Step Guide

### 1. **Download the Rule**
- Click "Download Multi-Site Rule" button
- Save the JSON file to your computer

### 2. **Open Consent O Matic**
- Click the Consent O Matic icon in your browser toolbar
- Click "Options" or "Settings"

### 3. **Import the Rule**
- Click "GDPR Consent Rules Editor"
- Click "From Pasted JSON"
- Open the downloaded JSON file and copy its contents
- Paste the JSON into the text area
- Click "Load"

### 4. **Save the Rule**
- Click "Save Custom Rule" in the left menu
- Give it a name like "Pharmacy Websites"
- Click "Save"

### 5. **Test the Rule**
Visit each website and check if the cookie banner disappears automatically:
- https://margispharmacy.com
- https://midtowncompoundingpharmacy.ca  
- https://beyondrx.ca

## 🎯 **What the Rule Does**

Your generated rule will:
- **Detect cookie banners** on all three pharmacy websites
- **Automatically click "Accept"** buttons
- **Hide the banners** so you don't see them again
- **Work on future visits** to these sites

## 🔧 **If It Doesn't Work**

1. **Check the website** - some sites change their banner structure
2. **Try individual rules** - create separate rules for each website
3. **Use browser developer tools** (F12) to inspect the banner elements
4. **Contact support** if you need help adjusting the selectors
