🍪 CMP Mapper + Consent O Matic Workflow

│                    YOUR CMP MAPPER PROTOTYPE                    │
│                                                                 │
│  Website with Unknown Cookie Banner                            │
│           ↓                                                     │
│  CMP Mapper Analyzes:                                          │
│  • Detects banner elements                                     │
│  • Finds button selectors                                      │
│  • Generates JSON rule                                         │
│           ↓                                                     │
│  Output: JSON Rule File                                         │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                    CONSENT O MATIC EXTENSION                    │
│                                                                 │
│  1. Open "GDPR Consent Rules Editor"                           │
│  2. Click "From Pasted JSON"                                   │
│  3. Paste your JSON rule                                       │
│  4. Click "Load"                                               │
│           ↓                                                     │
│  Rule Editor Interface Opens:                                   │
│  • Left: Draggable elements (Matchers & Actions)               │
│  • Right: Rule configuration area                              │
│           ↓                                                     │
│  5. Drag elements to configure:                                 │
│     - Detectors: How to find the banner                        │
│     - Methods: What actions to take                            │
│           ↓                                                     │
│  6. Click "Save Custom Rule"                                   │
│  7. Give it a name (e.g., "MargisPharmacy")                    │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                        AUTOMATIC EXECUTION                      │
│                                                                 │
│  When you visit the website:                                   │
│  • Consent O Matic detects the banner                          │
│  • Applies your saved rule                                     │
│  • Automatically clicks buttons or hides banner               │
│  • No more cookie popups!                                      │
└─────────────────────────────────────────────────────────────────┘
