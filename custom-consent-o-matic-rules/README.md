## 🚀 How to Use

1. **Copy the raw URL** of any rule file
2. **Open Consent O Matic** extension
3. **Go to 'GDPR Consent Rules Editor'**
4. **Click 'From URL'** and paste the raw URL
5. **Click 'Load'** to import the rule
6. **Click 'Save Custom Rule'** to make it permanent
